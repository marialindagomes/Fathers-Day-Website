# 💙 Father's Day Website

A simple and heartfelt Father's Day website created to celebrate and wish my father a Happy Father's Day.

This project was created as a small personal web development project using **HTML, CSS, and JavaScript**.

## ✨ Features

- 🎉 Personalized Father's Day greeting
- 💙 Heartfelt message for my father
- 📸 Personal family photos
- 🎨 Custom styling and layout
- ✨ Interactive elements using JavaScript
- 📱 Simple and responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Chrome
